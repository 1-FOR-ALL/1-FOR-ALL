# 專案留言板：線稿規格

產品：**1 for ALL 企業資訊入口（EIP）**，模組是「專案管理區 › 專案留言板」。
本資料夾是**初步線稿**，重點放在功能、資訊結構和頁面流程，不定視覺樣式。

## 檔案

| 路徑 | 內容 |
| --- | --- |
| `wireframes/list.html` | 畫面 1：留言列表 |
| `wireframes/detail.html` | 畫面 2：單則留言與回覆 |
| `wireframes/new.html` | 畫面 3：新增留言（編輯也共用這個表單） |
| `wireframes/wireframe.css` | 線稿用樣式，只有黑線、白底 |
| `screenshots/*.png` | 三個畫面在 1440px 寬時的截圖 |
| `design/tokens.json`、`design/UI-Guideline.md` | 正式視覺規範（色彩、字級、間距），**線稿階段先不要套用** |

## 頁面流程

```
list.html ──「新增留言」──────────────▶ new.html ──「送出」／「取消」──▶ list.html
    │
    └── 點標題 或「某某等 N 人已回覆」──▶ detail.html ──「返回留言列表」──▶ list.html
```

## 共用框架（三頁都有）

- **左側欄**，寬 232px：
  - 品牌字「1 for ALL／企業資訊入口」。
  - 導覽「專案管理區」（目前所在頁）。
  - 底部固定放帳號區：頭像、使用者名稱、「設定」。
- **頁籤標題**：「專案留言板」，旁邊的數字徽章是「被提及且未讀」的留言數，數量是 0 時隱藏。
- 手機寬度時，側欄要能疊到內容上方，或改成收合選單。

## 1. 留言列表（list.html）

**工具列**
- 讀取狀態：總留言數、未讀數、被提及數。
- 搜尋框：搜尋標題、內容、作者，加上「搜尋」按鈕。
- 「新增留言」按鈕。

**留言卡片**（每則一張）
- 狀態標籤，可以同時出現多個：`置頂`、`@ 提及你`、`未讀`。
- 標題，點了進入單則留言。
- 右上角操作：`置頂`／`取消置頂`（依目前狀態切換）、`封存`。
- 作者頭像、名稱、發文時間。
- 內文摘要，最多顯示 3 行。
- 回覆者摘要：「A、B 等 N 人已回覆」加上 2 個疊在一起的頭像，點了進入單則留言。
- 回覆數、點擊數。

**排序**：置頂的留言在最上面，其餘依最後更新時間由新到舊。

## 2. 單則留言（detail.html）

- 「返回留言列表」。
- 標題區：
  - 狀態標籤、標題、作者、發文時間。
  - 「編輯留言」和「刪除留言」，**只有作者本人或管理員看得到**；刪除前要二次確認。
- 內文：
  - 支援換行。
  - `@成員` 要另外標示。
  - 下方列出附件（圖片、檔案），顯示檔名和大小。
- 回覆數、點擊數。打開這一頁就算一次點擊，同時把這則標成已讀。
- **回覆區**
  - 輸入列：目前使用者的頭像、輸入框（可以 `@` 標記成員）、「送出」。
  - 回覆列表依時間由舊到新，每則有頭像、名稱、時間、內容。
  - **只有自己的回覆**才顯示「編輯」「刪除」。

## 3. 新增／編輯留言（new.html）

- 「取消，返回列表」。
- 表單：
  - 表頭顯示發文者和時間。
  - 標題：**必填**。
  - 內容：多行文字，可以 `@` 標記成員。
  - 已上傳的附件會列在下方，每個都能用 ✕ 移除。
  - 「上傳圖片」「上傳檔案」兩顆按鈕。
  - 勾選框「發布後置頂」。
  - 「送出」。
- 編輯模式沿用同一個表單：預先填入原本的內容，表頭改成「編輯留言」。

## 資料欄位（建議）

```ts
Post {
  id, title, body, authorId, createdAt, updatedAt,
  pinned: boolean, archived: boolean,
  attachments: Attachment[],   // { name, size, type: 'image' | 'file', url }
  mentions: userId[],
  replyCount, viewCount
}
Reply { id, postId, authorId, body, createdAt, mentions: userId[] }
ReadState { userId, postId, readAt }   // 用來算「未讀」和「被提及且未讀」
```

## 還沒決定的事（實作前要確認）

- 封存後的留言要放在哪裡看？是否要做「封存區」？
- 置頂的權限：所有人都能置頂，還是只有管理員？
- 回覆是否支援附件、是否支援巢狀回覆？
- 搜尋是即時篩選，還是按下按鈕才搜尋？
