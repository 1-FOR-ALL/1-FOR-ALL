# EIP UI Guideline

企業內部入口（EIP）的視覺規範，v2。風格是**白底、黑字、粗黑標題、平面色塊**。整套只用兩個主色：**灰藍**和**奶油黃**。其他需求都用這兩色往深或往淺調出來。**磚紅**只保留給警告和少量強調。

## 設計原則

1. **白底黑字是主角。** 頁面 90% 以上面積是 `paper`，文字用 `ink` / `ink-2`。黑、白、灰是中性色，不算主色。
2. **只有兩個主色。** 灰藍 `blue-200` #C9D6DF、奶油黃 `yellow-200` #F3E3A3。不要另外加色相。需要更多變化的時候，在同色系裡往淺（`-50` `-100`）或往深（`-300` 以上）取色。
3. **顏色 = 功能分區。** 灰藍代表「公司共用」，奶油黃代表「個人作業」。同一個色系裡用深淺區分不同頁面（見下表）。
4. **警告色要少用。** `warning` 磚紅只用在未讀、今日、錯誤、重要公告、刪除這類地方，一個畫面最多 3 處。
5. **直角、平面、無陰影。** 卡片 `radius-0`，用色塊和 `line` 分隔，不用陰影或漸層。
6. **粗黑標題加黑色粗底線。** 頁面標題用 `h1`（字重 900），區塊標題下方加 `rule-width` 的 `line-strong` 底線。

## 色彩

### 主色階

| 階 | 灰藍 | 奶油黃 | 用途 |
| --- | --- | --- | --- |
| 50 | `blue-50` #F2F5F8 | `yellow-50` #FDF9EC | hover 底、斑馬紋 |
| 100 | `blue-100` #E6EDF1 | `yellow-100` #FAF2D3 | Hero、大面積淺底 |
| **200 主色** | **`blue-200` #C9D6DF** | **`yellow-200` #F3E3A3** | 卡片、標籤、色點、行事曆事件 |
| 300 | `blue-300` #A9BCC9 | `yellow-300` #EBD27A | 第二個頁面的主色塊、hover |
| 400 | `blue-400` #8AA2B3 | `yellow-400` #DDBE52 | 頁籤底線、進度條、圖表（非文字） |
| 600 | `blue-600` #556F82 | `yellow-600` #8A6F1C | 白底上的彩色文字或連結 |
| 800 | `blue-800` #2E3F4C | `yellow-800` #5A4813 | 色塊上的彩色文字或 Icon |

### 警告色

| token | 色票 | 用途 |
| --- | --- | --- |
| `warning` | #C23A28 磚紅 | 未讀點、今日、錯誤文字、刪除按鈕 |
| `warning-soft` | #F8E1DD | 錯誤提示列、警示 Banner 底 |
| `warning-strong` | #9A2C1E | `warning-soft` 上的文字、刪除 hover |

> 「成功／完成」不另外給綠色。用 `ink` 加勾選 Icon，或用 `blue-200` 標籤表示。

### 功能頁對照

| 功能頁 | 色系 | 主色塊 | 大面積淺底 | 側欄色點 |
| --- | --- | --- | --- | --- |
| 公司首頁 | 灰藍・公司共用 | `blue-200` | `blue-100` | `blue-200` |
| 公告管理區 | 灰藍・公司共用 | `blue-300` | `blue-50` | `blue-300` |
| 個人工作台 | 奶油黃・個人作業 | `yellow-200` | `yellow-100` | `yellow-200` |
| 文件管理區 | 奶油黃・個人作業 | `yellow-300` | `yellow-50` | `yellow-300` |

**規則**
- 主色塊（50 到 400）上的文字一律用 `ink`，對比都在 7:1 以上。
- 白底上要用彩色文字時，只能用 `-600` 以上的階；`-400` 以下不能當文字色。
- 灰藍和奶油黃不在同一張卡片裡混用。公司首頁的快速入口是例外，它就是兩色系並排的導覽。
- 色塊不要超過畫面的 1/3。大面積請用 `-50` 或 `-100`。
- 同一個色系裡的兩個頁面靠深淺分辨。因為深淺差距有限，**頁面標題和側欄文字一定要出現**，不能只靠顏色辨識。

## 字體

- 主字體：**Noto Sans TC**（Google Fonts，字重 400 / 700 / 900），英數字 fallback 用 **Inter**。
- 數字、編號、日期、檔案大小：**JetBrains Mono**。

| 樣式 | 尺寸 / 行高 | 字重 | 使用 |
| --- | --- | --- | --- |
| display | 40 / 48 | 900 | Hero 主標 |
| h1 | 28 / 36 | 900 | 頁面標題 |
| h2 | 20 / 28 | 700 | 區塊標題（下方加黑粗線） |
| h3 | 16 / 24 | 700 | 卡片標題 |
| body | 15 / 24 | 400 | 內文 |
| caption | 13 / 20 | 400 | 時間、作者、說明 |
| label | 12 / 16 | 700 | 標籤、側欄分組名 |

## 版面

- 左側導覽寬 `sidebar-width` 232px，底色 `paper-soft`。選中的項目反白成 `ink` 底加白字，左側顯示該頁的 8px 色點。
- 側欄底部固定放「個人帳號管理」：頭像、名稱、設定 Icon。
- 主工作區上方是 `topbar-height` 64px 的頂部列（頁面標題、搜尋、通知）。內容區外距 `space-8`，卡片 gutter `space-6`，用 12 欄格線。
- 右下「對話群組」收合時是 `radius-full` 的黑色膠囊按鈕（白字，未讀數用 `warning`）；展開後是 `chat-dock-width` 320px 的白色面板，外框 1px `line`。

## 元件要點

- **按鈕**
  - 主要按鈕：`ink` 底、白字。
  - 次要按鈕：白底、1px `ink` 框。
  - 危險操作：`warning` 底、白字。
  - 共通：`radius-sm`，高度 36px（觸控裝置用 44px）。
- **卡片**：直角，用功能色塊，或白底加 1px `line`；標題用 `h3`，右上可以放線條 Icon。
- **頁籤**：文字用 `body-strong`，選中時下方加 `rule-width` 粗的底線，顏色用該頁色系的 `-400`。
- **標籤**：字級 `label`，`radius-sm`。一般標籤用 `blue-200` 或 `yellow-200` 底；警告標籤用 `warning-soft` 底加 `warning-strong` 字。
- **行事曆**：日期用黑字；公司事件用 `blue-200` 底，個人事件用 `yellow-200` 底；今日用 `warning` 圓框。
- **提示列**：一般資訊用 `blue-100` 底，錯誤或警告用 `warning-soft` 底。
- **Icon**：1.5px 線條風格（建議 Lucide），黑色，尺寸 24 / 20 / 16px。

## 無障礙

- 正文對比 ≥ 4.5:1；`ink-3` 只用在 placeholder 和停用狀態。
- 功能區不能只靠顏色辨識：側欄和頁面標題永遠要有文字。
- 警告除了紅色，還要搭配 Icon 或文字（例如「錯誤」「未讀 3」）。
- 焦點樣式：2px `focus` 外框，2px offset。
